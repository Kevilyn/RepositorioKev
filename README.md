# 🎯 Desafio Criativo — Extraindo Insights do Feedback de Clientes Bancários

Este repositório reúne minha entrega para o desafio criativo da DIO, com foco na criação de um prompt estruturado para análise de feedbacks de clientes bancários com apoio de Inteligência Artificial.

## 💡 Proposta

A ideia foi desenvolver um prompt que vá além de uma análise simples de sentimento.

O projeto propõe um **Radar de Fricção e Confiança na Jornada de Renegociação Bancária**, capaz de orientar a IA a identificar:

- principais pontos de fricção na jornada;
- sinais de perda ou ganho de confiança;
- esforço percebido pelo cliente;
- riscos de abandono;
- padrões de reclamações e elogios;
- oportunidades de melhoria;
- prioridades para times de negócio, experiência e canais digitais.

## 🧠 Diferencial da abordagem

Um dos principais diferenciais do prompt é a separação entre:

- **Fato:** informação explicitamente presente nos feedbacks;
- **Indício:** padrão observado que precisa de validação;
- **Hipótese:** possível explicação que não deve ser tratada como conclusão sem evidência adicional.

Essa estrutura ajuda a reduzir conclusões precipitadas e torna a análise mais segura e útil para tomada de decisão.

## 🔐 Cuidados com dados sensíveis

O prompt também considera boas práticas para o uso de IA em contexto bancário, incluindo:

- uso apenas dos dados fornecidos;
- proibição de inventar números, causas ou conclusões;
- remoção de dados pessoais e bancários;
- sinalização de limitações dos dados;
- cuidado para não transformar casos isolados em tendências;
- diferenciação entre evidência, indício e hipótese.

## 📊 Estrutura esperada da resposta da IA

A saída foi pensada para ser clara e acionável, contendo:

1. resumo executivo;
2. radar de fricção e confiança;
3. ranking de prioridades;
4. voz do cliente;
5. oportunidades de ação;
6. perguntas que os dados ainda não respondem.
